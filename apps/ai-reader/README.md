# English Room · 可运行网页 MVP 0.1

iPad 优先的英语点读网页应用。基于 [产品需求](../../docs/ai-reader/README.md) 开发，不覆盖仓库已有英语学习笔记。

## 目前实现
- 首页书架、继续阅读、精简进度和今日待复习数
- 完整句子点击讲解（预制中文释义、重点词组、日常实用表达）
- 使用浏览器 SpeechSynthesis 朗读整句或单独词组；默认美式英语，可选英音/澳音与语速
- 词组独立 \`+\` 收藏、收藏整句、当前章节备忘录式笔记、自由备注
- 跨书复习中心、单词/词组/句子过滤、按答题难度安排下一次复习
- 章节难度/学习感受反馈
- 可点击气泡的咖啡馆情景演示
- 导入 TXT / Markdown / 结构化 JSON 教材，导出/恢复本地 JSON 备份
- 复制教材制作提示词给自己的 AI；导入 AI 生成的 JSON

## 尚未实现
自动 GPT/Claude/Gemini MCP 读写、远程模型调用、真正的高质量神经语音预生成、云备份/会员/登录、复杂 EPUB 解析、导入文本的自动 AI 加工。

## 本地运行
可用静态文件服务器启动本目录：\`python3 -m http.server 8000\`，在浏览器打开 \`http://localhost:8000\`。项目无运行时服务器依赖；也可由 Vite 静态部署。

## 数据注意
学习记录只保存在当前浏览器的 \`localStorage\`。切换设备或清空网站数据会丢失，请使用设置内导出备份。此 MVP 的样例教材和说明并不等于正式 AI 生成课程。
