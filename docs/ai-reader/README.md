> 版本：v0.1 需求基线｜记录时间：2026-11-11（Asia/Kuala_Lumpur）

> 工作名称：AI English Reader（**非最终品牌**）。对话中出现的“Muse”指帮助用户制作原型的第三方 AI，不表示本产品属于该公司。

## 一句话定义
一款 **iPad 优先、网页即用、AI 可接入、用户内容自主管理** 的沉浸式英语阅读学习工具：像电子书一样阅读、按完整句子点读、把不会的单词/词组/句子快速收进笔记，再按间隔复习巩固；AI 在阅读之前加工教材，在学习之后基于记录调整教材。

## 产品核心理念（不可轻易改变）
1. **阅读第一**：轻松读书，不把每句话变成考题；没有必要就不弹出教学 UI。
2. **实战优先**：英语解释要说明日常如何表达，尤其是真实生活对话。
3. **学习尽量无负担**：不熟悉的内容一键收藏；只集中复习不熟悉的。
4. **AI 提前备课**：分句、翻译、重点表达、生活例句等在准备教材阶段完成；阅读点击时立即展示，不依赖实时生成。
5. **用户掌控 AI**：AI 可自动优化下一课，用户能通过自然语言随时干预课程与模型选择。
6. **本地优先与数据可迁移**：内容/学习数据应本地可用、可导出；会员可选择云端备份。
7. **iPad 网页优先**：无需安装 App，横屏优先考虑阅读 + 当前章节笔记；竖屏也要完整适配。
8. **极简排版**：层级明确，留白充分，不堆大量标签、数据卡片或无意义提示词。

## 已确认的三大核心页面
- **首页 / 书架**：书籍封面、继续阅读、进度、重要通知、创建/导入教材入口。
- **阅读器**：完整句子点读，预制讲解卡片，独立词组收藏；横屏右侧可打开当前章节备忘录式笔记。
- **复习中心**：将收藏的词、词组、句子单独分类，按间隔复习曲线安排每日复习。

另有章节复盘、AI 教材管理、插画情景交互和设置；不要求它们全挤在阅读页。

- 所有确认过的产品改动，以本目录文档为**需求事实来源**；先更新文档并提交，再进行影响架构的实现。
