# iPad 端 UI / UX 基线

版本 v0.1 · 2026-11-11

## 设计原则
- 整体：像高质量电子书阅读器，而不是复杂的后台仪表盘。
- **简洁、大气、明确的信息层级**：大字号标题、舒适行距、适当留白、少量点缀色；不叠加大量教学小标签、徽章、提示、仪表卡。
- 用户认可此前概念图的舒适简约方向；**现阶段没有确认精确品牌色、字体、LOGO**。先采用暖白/米白底、清晰英文排版与克制的淡色强调。
- 不直接复制微信读书/其他产品的受保护视觉素材；借鉴成熟的沉浸阅读交互。
- 主要设备 iPad Safari（横屏优先，兼容竖屏）；网页响应式，不要求安装 App。

## 页面 1：首页 / 书架
优先顺序：
1. 当前阅读的书、章节、进度、继续阅读；
2. 书架封面网格：用户导入书 / AI 生成教材 / 合法可用公开教材；
3. “AI 创建教材”、“导入书籍”入口；
4. 小范围必要通知：今天有待复习、生成结果就绪、备份失败等。

**不要**首页堆满连续打卡 KPI、十几个活动卡、复杂分类。简单进度足够。

## 页面 2：沉浸阅读器
- 以“整页文章”呈现，正文间按**完整句子**设点击热区；可包含少量 AI 预先制作的插图。
- 顶部：返回、书名/章节、字号、语音/口音与更多设置，保持克制。
- 底部：目录、进度/翻页、笔记开关等，尽量参考电子书阅读习惯。
- 用户点击某一句：
  - 句子轻微高亮；
  - **就在附近弹出卡片**，不要路由跳页；
  - 卡片含完整英文句子、整句播放、中文解释、精选重点词组、真实生活表达；
  - 每个重点词组一行，显示“词/词组 ｜ 播放 ｜ 中文意义 ｜ **＋**”，可以单独收藏；
  - 整句独立收藏；点击「＋」不出现确认模态框，可显示短暂保存状态；
  - 内容已提前生成，读书时无“AI 正在思考”等待。
- 点击文章空白、按关闭或切换句子，可以收起/切换卡片。

- 阅读区占**大部分**宽度，笔记侧栏较窄；左右比例适配屏幕。
- **笔记栏不显示**“Words / Phrases / Sentences”分类导航、记忆曲线、今天复习统计等。
- 侧栏是当前书/当前章的轻量备忘录，不是第二个学习主屏幕。
- 句子弹出卡片应避免与侧栏重叠，空间不足时自适应位置或宽度。

### 竖屏阅读布局
- 阅读正文占完整宽度；减少永久工具栏和遮挡。
- 点击句子仍显示紧凑讲解卡。
- 当前章节笔记通过按钮打开临时抽屉/叠层，关闭后继续阅读；具体控件位置待设计。
- 辅助插画应不影响连续阅读。

## 页面 3：复习中心
- 与阅读界面分离，通过主页/底部导航或边栏进入。
- “今日待复习”作为唯一主要状态；可切换单词 / 词组 / 句子分类、历史、薄弱项。
- 单张复习卡先回忆、再看答案，评价忘记/困难/掌握/轻松，调整下次复习。
- 有书籍、章节、原句来源入口；不需要强制完成所有条目。
- 曲线安排先沿用旧仓库的 +1、+3、+7、+14、+30、+60 天作为候选。

## 子页：章节结束学习复盘
- 四档难度 / 哪方面困难 / 自由备注；保持轻量。
- AI 根据反馈计划下一章，但用户有决定权，原文教材不被擅改。

## 子页：插图情景练习
- 插画是可选教材内容，不是整站的背景装饰。
- 视觉上像童年英语课本的情景插画：咖啡馆、交通、朋友聊天、工作等。
- 对话气泡 **对应可点的独立文本层**：点击即句子点读、解释、加入笔记；可进一步加回复选择/扮演。
- 先按静态场景 + 对话气泡实现；高级互动可后续扩展。

## 设置页 / 轻量工具
- 语音：默认美式英语；后续用户选口音/音色/语速。
- AI：允许模型和提供商自定义；首版无须内嵌 AI 自动推理。
- 数据：本地保存、导出/导入；会员未来连接个人网盘备份。
- 字号、主题等根据实际测试精简配置；不必出现复杂配置表。
